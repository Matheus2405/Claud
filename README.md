# Claud — Sistema de Cadastramento

Sistema de cadastramento desenvolvido em **Java com Spring Boot**, com foco na construção de uma API REST e na persistência de dados utilizando **PostgreSQL**.

O projeto faz parte do meu processo de aprendizado e prática em desenvolvimento **Backend Java**, aplicando conceitos de arquitetura em camadas, APIs REST, persistência de dados e integração com banco de dados.

## 🚀 Tecnologias

* **Java**
* **Spring Boot**
* **Spring Data JPA**
* **PostgreSQL**
* **Maven**
* **Postman**
* **Git/GitHub**


## 📌 Objetivo

O objetivo do projeto é desenvolver, na prática, uma aplicação backend utilizando **Java e Spring Boot**, passando pelas principais etapas de construção de uma API:

* Criação de endpoints REST;
* Organização da aplicação em camadas;
* Integração com banco de dados;
* Persistência de informações;
* Manipulação de dados;
* Testes das requisições utilizando Postman.

## 🔧 Status do projeto

🚧 **Em desenvolvimento**

O projeto ainda está sendo desenvolvido e novas funcionalidades serão adicionadas conforme a evolução da aplicação.

Durante o desenvolvimento do Claud, estou praticando conceitos importantes para desenvolvimento Backend Java, principalmente:

* Desenvolvimento de APIs REST;
* Spring Boot;
* Spring Data JPA;
* Arquitetura em camadas;
* Integração com PostgreSQL;
